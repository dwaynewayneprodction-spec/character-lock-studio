Character Lock Studio Website

This is the front website. It can be uploaded online without Python or Node.

How to open:
1. Unzip the folder.
2. Double-click index.html.

How to put online:
1. Go to netlify.com/drop
2. Drag this whole folder into the page.
3. Netlify gives you a live website link.
